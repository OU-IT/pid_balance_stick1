# STM32F4 螺旋桨平衡杆（倒立摆）

基于 STM32F4 标准外设库的倒立摆平衡系统。顶部电机带动螺旋桨产生推力，通过 MPU6050 检测倾角，卡尔曼滤波融合姿态，PID + 前馈控制输出 PWM 驱动电调，使杆子保持目标角度。

## 硬件连接

| 功能          | 引脚   | 说明            |
| ----------- | ---- | ------------- |
| MPU6050 SCL | PB6  | I2C1_SCL      |
| MPU6050 SDA | PB7  | I2C1_SDA      |
| 电调 PWM      | PA1  | TIM2_CH2，50Hz |
| 串口 TX       | PA9  | USART1，115200 |
| 串口 RX       | PA10 | USART1        |

> 电调电源建议与 MCU 隔离，共地。

## 文件结构

text

main.c                  主程序、SysTick、TIM3、控制主循环
motor.c / motor.h       PWM 初始化与电机速度控制
mpu6050.c / mpu6050.h   MPU6050 驱动、角度转换、零偏校准
pid.c / pid.h           PID 控制器
kalman.c / kalman.h     一维卡尔曼滤波
uart.c / uart.h         USART1 初始化与 printf 封装
i2c.c / i2c.h           I2C1 底层读写
delay.c / delay.h       软件延时

## 使用说明

1. 上电后保持杆子静止且接近直立，等待约 1 秒。

2. 系统自动校准陀螺仪零偏，完成后串口输出 `System Ready`。

3. 系统进入闭环控制，根据倾角自动调整螺旋桨推力。

4. 调试时建议先拆下螺旋桨或固定杆子，确认方向正确后再实际运行。

5. 取消 `main.c` 中串口打印注释可观察角度和输出。

## 控制流程

text

上电 → 初始化 → MPU6050 校准 → 初始化 PID
  ↓
每 4ms（TIM3）:
  读取 MPU6050 → 计算角度 → 卡尔曼滤波
  → PID + 余弦前馈 → 限幅保护 → 输出 PWM

## 关键参数

| 项目                        | 值                   |
| ------------------------- | ------------------- |
| 控制周期 `dt`                 | 4ms（TIM3）           |
| 卡尔曼 `Q` / `R`             | 0.8 / 1.5           |
| PID `K_P` / `K_I` / `K_D` | 5.76 / 0.01 / 7.85  |
| 目标角度 `expect`             | 81.0°               |
| 前馈 `K_ff`                 | 35.0                |
| 输出限幅                      | -100 ~ 100          |
| 安全保护                      | 倾角 > 95° 时输出置 0     |
| PWM 中位停止                  | 1500us（1000~2000us） |

## 注意事项

1. `TIM3_INIT` 注释 `//4s` 应为 4ms。

2. `main.c` 注释 `pa9->rxd pa10->txd` 写反，实际 PA9=TX，PA10=RX。

3. `pid.c` 中积分项 `p_s->i` 未累加，`K_I` 实际不起作用。

4. 电调需设置为双向模式。

5. 角度正负、`expect`、前馈方向与传感器安装有关，需实际调试。

6. 螺旋桨高速旋转，调试务必注意安全。
